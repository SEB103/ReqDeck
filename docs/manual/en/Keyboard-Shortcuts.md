# Keyboard Shortcuts

The menus show these shortcuts next to their commands.

## Everywhere

| Keys | Action |
|---|---|
| **F1** | show or hide help for the control under the pointer or in focus |
| **Esc** | close the help panel |
| **Ctrl+K** | find a request or a command |
| **Ctrl+N** | new request |
| **Ctrl+O** | open a workspace |
| **Ctrl+S** | save the workspace |
| **Ctrl+Shift+S** | save the workspace under another name |
| **Ctrl+Q** | quit |

## Requests and tabs

| Keys | Action |
|---|---|
| **Ctrl+Enter** | send the request, also from inside the tables |
| **Ctrl+Tab** / **Ctrl+Shift+Tab** | next / previous tab |
| **Ctrl+W** | close the current tab |
| **Tab** | move through method, URL, and Send |
| **Enter** or **Tab** after `{{` | insert the selected variable |

## Response

| Keys | Action |
|---|---|
| **Ctrl+F** | search in the response body |
| **F3** / **Shift+F3** | next / previous match |

## Collection tree

| Keys | Action |
|---|---|
| **↑** / **↓** | select the previous / next item |
| **→** / **←** | expand / collapse a folder |
| **F2** | rename |
| **Delete** | delete the selected items |
| **Ctrl+click**, **Shift+click** | select several items |

Shortcuts do not fire while a system file dialog is open.
