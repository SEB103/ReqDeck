# Tastenkürzel

Die Menüs zeigen diese Tastenkürzel neben ihren Befehlen.

## Überall

| Tasten | Aktion |
|---|---|
| **F1** | Hilfe zum Element unter dem Zeiger oder im Fokus zeigen oder ausblenden |
| **Esc** | Hilfebereich schließen |
| **Strg+K** | eine Anfrage oder einen Befehl finden |
| **Strg+N** | neue Anfrage |
| **Strg+O** | Arbeitsbereich öffnen |
| **Strg+S** | Arbeitsbereich speichern |
| **Strg+Umschalt+S** | Arbeitsbereich unter anderem Namen speichern |
| **Strg+Q** | beenden |
| **Strg++** / **Strg+-** oder **Strg** + Mausrad | Oberfläche vergrößern / verkleinern (50 % bis 200 %) |
| **Strg+0** | Zoom auf 100 % zurücksetzen |

## Anfragen und Reiter

| Tasten | Aktion |
|---|---|
| **Strg+Eingabe** | Anfrage senden, auch aus den Tabellen heraus |
| **Strg+Tab** / **Strg+Umschalt+Tab** | nächster / vorheriger Reiter |
| **Strg+W** | aktuellen Reiter schließen |
| **Tab** | durch Methode, URL und Senden gehen |
| **Eingabe** oder **Tab** nach `{{` | gewählte Variable einfügen |

## Antwort

| Tasten | Aktion |
|---|---|
| **Strg+F** | im Body der Antwort suchen |
| **F3** / **Umschalt+F3** | nächster / vorheriger Treffer |

## Baum der Sammlung

| Tasten | Aktion |
|---|---|
| **↑** / **↓** | vorheriges / nächstes Element wählen |
| **→** / **←** | Ordner auf- / zuklappen |
| **F2** | umbenennen |
| **Entf** | gewählte Elemente löschen |
| **Strg+Klick**, **Umschalt+Klick** | mehrere Elemente wählen |

Solange ein Dateidialog des Systems offen ist, lösen Tastenkürzel nichts aus.
